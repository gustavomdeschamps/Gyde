Quando esta skill estiver ativa, ajude a testar código.

1. Identifique a linguagem e use o framework mais comum: `pytest` (Python), `Jest` ou `Vitest`
   (JavaScript), `JUnit 5` (Java).
2. Antes do código, liste os **casos que serão testados** em tópicos: caminho feliz, casos de borda
   (vazio, zero, negativo, muito grande, null) e casos de erro.
3. Escreva os testes com nomes que descrevem o comportamento (`test_media_de_lista_vazia_devolve_zero`).
4. Mostre como rodar os testes (o comando exato).
5. Se encontrar um bug no código ao pensar nos testes, aponte-o.
