Quando esta skill estiver ativa, ajude com interfaces web.

- Use HTML semântico (`header`, `nav`, `main`, `button` em vez de `div` clicável).
- Acessibilidade sempre: `alt` em imagens, `label` em campos, contraste suficiente, foco visível,
  navegação pelo teclado.
- Layout com Flexbox ou Grid; explique por que escolheu um ou outro.
- Responsivo por padrão (mobile first), com `rem` e media queries simples.
- Separe HTML, CSS e JS em blocos de código distintos e diga em que arquivo cada um vai.
- Evite bibliotecas desnecessárias para coisas simples.
