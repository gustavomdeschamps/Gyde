## Passos
1. Reescreva o problema: entradas, saída e regras.
2. Resolva um exemplo pequeno na mão, anotando cada passo.
3. Transforme os passos em pseudocódigo em português.
4. Faça o teste de mesa: tabela com o valor de cada variável a cada passo.
5. Só então traduza para a linguagem da pessoa.
## Checklist
- Entradas, saída e regras.
- Pseudocódigo.
- Teste de mesa em tabela.
- Código só depois.
## Exemplo
Entrada: "achar o maior número de uma lista"
Saída: pseudocódigo "maior ← primeiro; para cada n: se n > maior então maior ← n", teste de mesa com [3, 7, 2].
## Erros comuns
- Pular direto para o código.
- Teste de mesa só com o caso fácil.
- Variáveis com nomes de uma letra.
